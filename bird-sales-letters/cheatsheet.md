# Cheatsheet — Drayton Bird, How to Write Sales Letters that Sell

Regras de decisão ("Se X → Y"), tabelas e números do autor. Os números são da época do livro e de testes específicos; servem como ordem de grandeza histórica.

## Decisões rápidas

- **Se o leitor não conhece você nem o produto** → explique o que é antes de vender (estágio 1, ch03).
- **Se já há concorrentes parecidos** → compare ponto a ponto e prove a vantagem (estágio 2 ou 3, ch03).
- **Se o produto é conhecido por todos** → pouca explicação, foco nas forças competitivas (estágio 3, ch03).
- **Se o pedido é pagar antes** → o mais difícil; reforce confiança, garantia e prova (ch02).
- **Se o pedido é só experimentar ou visitar** → mais fácil; um benefício claro basta (ch02).
- **Se o leitor já é cliente** → personalize pelo nome e peça indicação; é mais barato que prospectar (ch05, ch16).
- **Se é um prospect frio** → use cargo ou nada na salutação; personalização cara não se paga (ch16).
- **Se a oferta é fraca** → use curiosidade na abertura e prometa só o que a oferta cumpre (ch09).
- **Se o produto é caro ou exige compromisso** → carta mais longa, prova e brochura (ch16).
- **Se o produto é barato e conhecido** → carta curta pode bastar, com oferta forte (ch06, ch16).
- **Se a empresa é desconhecida** → não ponha o nome no topo; benefício primeiro (ch15).
- **Se a empresa é conhecida e confiável** → o nome no papel pode dobrar a resposta (ch15).
- **Se você já escreveu várias vezes sem resposta** → o remetente pode ficar oculto no envelope; mude o argumento (ch08).
- **Se a carta faz uma afirmação forte** → double take e prova logo depois (ch11).
- **Se o leitor precisa de muito convencimento** → use as provas, a garantia e as objeções (ch11).
- **Se o texto parece cheio de jargão** → troque cada termo técnico por um simples; teste com um leigo (ch13).
- **Se a frase é longa (mais de 32 palavras)** → divida (ch13).
- **Se o texto usa "nós" e "eu" mais do que "você"** → reescreva para o leitor (ch13).
- **Se há exclamação em excesso** → corte; deixe só a que realmente merece (ch13, ch15).
- **Se a página termina no meio de uma frase** → mude a quebra para o meio de uma ideia e diga "continue" (ch13).
- **Se a carta tem mais de uma página** → use cabeçalho e subtítulos (crossheads) (ch15).
- **Se a mensagem é cômica ou dramática sem relação com a oferta** → corte; a carta é para vender (ch01, ch14).
- **Se a assinatura é de alguém de baixo escalão** → procure um executivo; a assinatura muda a leitura (ch16).
- **Se a resposta exige pagamento** → só cobre se houver excesso de respostas ruins (ch16).
- **Se a resposta chega lenta** → responda no mesmo dia; cada dia de atraso perde resposta (ch16).
- **Se a pessoa pediu informação** → envie logo e com carta de venda, não só folheto (ch05, ch16).
- **Se o cliente reclama de tom** → deixe mudar frases; não mexa no conteúdo (ch16).

## Tabelas

### Os 5 elementos de uma carta bem-sucedida (ch00)
| Ordem | Elemento | Foco |
|---|---|---|
| 1 | Avaliar o produto | O que é, o que faz, melhor que o quê |
| 2 | Pensar no prospect | Quem é, o que quer, por que agiria |
| 3 | Oferta ou incentivo | O que você dá para agir |
| 4 | Técnica | Argumento, ordem, truques de leitura, layout |
| 5 | Talento | Menos importante que os quatro anteriores |

### Estágios do mercado (ch03)
| Estágio | Situação | O que fazer |
|---|---|---|
| 1 | Produto novo | Explicar e fazer querer; concorrente é o método antigo |
| 2 | Concorrentes entrando | Explicar e provar que é melhor |
| 3 | Concorrência feroz | Pouca explicação; focar em forças competitivas |

### Objetivos da carta por dificuldade (ch02)
| Objetivo | Dificuldade |
|---|---|
| Vender com pagamento antecipado | Alta |
| Testar sem obrigação | Média |
| Ir ao local e olhar | Baixa |

### Ordem de força de abertura (ch09)
| Ordem | Tipo |
|---|---|
| 1 | Benefício ou vantagem |
| 2 | Notícia de interesse |
| 3 | Curiosidade |

### Os 3 que mais fazem diferença (ch06)
1. Proposta. 2. Atenção. 3. Chamada para ação.

### Quem responde (ch16)
| Caso | Resposta esperada (ordem de grandeza) |
|---|---|
| Pesquisa com clientes (com pequeno incentivo) | cerca de 50% |
| Venda cara a desconhecido | cerca de 0,5% |
| Média de mala direta (UK, citada) | cerca de 4% |

### Atraso na resposta (ch16)
Cada dia de atraso pode reduzir cerca de 1% da resposta esperada. Ex.: 20% → 19,8%.

### Dados de testes citados (ch05-ch16)
| Teste | Resultado citado |
|---|---|
| Gold Card: carta nova vs anterior | 93% a mais |
| Envelope amarelo vs branco | +20% |
| Papel texturizado | até +90% |
| Oferta de três meses com preço anual mais alto | 3x vs preço baixo sem oferta |
| Garantia de devolução destacada | cerca de +50% |
| Formulário mais simples | +31% |
| Pedido com nome e endereço já impressos | cerca de +15% |
| Time close | +12% a +50% |
| Carta de 4 páginas vs 2 páginas | +52% |
| Foto de quem escreveu no cabeçalho | +30% |
| Brochura + carta vs carta sozinha | +9% a +28% |
| Retirar brochura (banco) | ROI +90% |
| Foto na carta sem brochura | +17% |

### Limites e metas citados pelo autor
| Item | Valor citado |
|---|---|
| Frase ideal (média) | cerca de 16 palavras |
| Frase máxima legível | 32 palavras |
| Cliente existente vs prospect | 3 a 8x mais fácil |
| Devolução de dinheiro típica | cerca de 3% (acima de 10% é sinal de problema) |
| Lembrete após a 1ª carta | cerca de metade das respostas |
| Anúncio com mais de 1.000 palavras | lido mais (pesquisa de 1988) |

## Tells & Smells (sinais de carta fraca)

- **Começa com "eu" ou "nossa empresa"** → ponto de vista errado (ch01).
- **Fala de "nós" mais que de "você"** → reescreva para o leitor (ch13).
- **Oferta mencionada sem descrição** ("condições especiais") → descreva valor, prazo, condição (ch07, ch12).
- **"Exciting", "fantastic", "strategic", "basically"** → cliché; corte (ch13).
- **Muitas exclamações** → ênfase perdida (ch13).
- **"Dear Sir/Madam"** para quem já é cliente → desleixo (ch16).
- **Carta sem assinatura ou com "p.p."** → falta de responsabilidade (ch05).
- **Folheto sem carta** → loja sem vendedor (ch05, ch16).
- **Cheque, prêmio ou gancho sem explicar** → pergunta sem resposta (ch09).
- **Abertura com gerúndio** ("realizing", "recognizing") → fraca e passiva (ch11).
- **Cabeçalho que revela tudo** → não há motivo para ler (ch15).
- **Só prova afirmações gerais** ("os melhores", "resultados incríveis") → sem números (ch11).
- **Depoimento genérico ou inventado** → perde credibilidade (ch11).
- **Prazo que se renova toda semana** → urgência falsa (ch12).
- **Cobrança com ameaça antes de qualquer pedido educado** → escalada errada (ch16).
- **Sem registro de qual carta gerou cada resposta** → impossível aprender (ch16).
