# Cola de decisão — Reason-Why Advertising (Kennedy)

| Número | O que significa | Capítulo |

## Fórmulas rápidas
- **Vendas necessárias** = custo do anúncio ÷ lucro por venda. (Ex.: $60 ÷ $1 = 60 vendas.)
- **Custo por consulta** = custo do espaço ÷ consultas do anúncio.
- **Vendas no varejo** = estoque inicial + reposição − estoque final.
- **Quanto custa o copy caro** = custo por consulta novo ÷ custo por consulta antigo. (Ex.: $14,20 ÷ $1,00 = 14 vezes.)

## Se X → Y
- Se o anúncio é bonito, mas não tem custo por venda conhecido → **não aprovar**. Medir antes.
- Se o produto é caro (classe pequena de compradores) → **convencer mais forte, com menos gente**.
- Se o produto é de massa → **linguagem simples, de primer-thought**.
- Se o copy novo custa mais por consulta que o histórico → **não trocar**.
- Se o copy atual custa pouco e roda há anos → **manter** e testar só variações.
- Se o custo por consulta do copy atual subiu com o tempo → **desgastou**; testar um Reason-Why novo.
- Se o canal é varejo → **o texto precisa vencer o vendedor concorrente**; use convicção de mala direta.
- Se o título não tem News-Interest → **reescrever o título antes de mexer no layout**.
- Se o título é "gancho" sem relação com o produto → **trocar por notícia do produto**.
- Se o anúncio é curto e não diz nada → **alongar com razão e prova**.
- Se o anúncio é longo e cheio de enfeite → **cortar**; o tamanho segue a função de venda.
- Se a equipe quer copiar um concorrente → **aplicar o teste do porquê** antes.
- Se o tom soa estranho para a classe → **mudar a voz**, não o argumento.
- Se o texto não tem chamada para ação → **escrever a clinching sentence**.
- Se a propaganda é de "nome" sem venda → **não é propaganda de venda**; redefinir o objetivo.

## Tells & smells (sinais de problema)
- "Manter o nome na frente das pessoas", "impressão geral", "influenciar vendas" → publicity, sem meta.
- "É bonito", "é catchy", "todo mundo admira" → critério de gosto, não de resultado.
- Muitas imagens e pouca frase com razão → Eye-Deep advertising.
- Título que não tem nada a ver com o produto → News-Interest falso; o leitor desconfia.
- Anúncio sem chave, endereço ou código de resposta → não há como medir.
- Trocar de copy sem olhar o custo por consulta → decisão às cegas.
- Moda copiada sem entender a razão → ovelha no salto.
- Anúncio sem fechamento que peça ação → o leitor vai embora sem nada.
- Texto que chama atenção de quem não compra → custo sem venda.
