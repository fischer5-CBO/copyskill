# ch01 — A Common Fallacy

## Core Idea
A frase "é boa campanha se as vendas sobem" é um mito. Vendas dependem de dezenas de fatores (produto, preço, distribuição, força de vendas, verba, concorrente). Julgar um anúncio só pelo caixa leva a conclusões erradas nos dois sentidos: uma campanha ruim pode parecer boa e uma campanha boa pode parecer ruim.

## Frameworks Introduced
- **Falácia das vendas (A Common Fallacy)** — quando alguém quer aprovar ou matar uma campanha só por vendas. Como usar: antes de julgar, liste as variáveis que mudaram no mesmo período e separe o efeito do anúncio.
- **Lista das variáveis de venda** — o autor cita 37 fatores que podem mover as vendas de uma marca, e a propaganda é só um deles. Como usar: faça a lista antes de qualquer análise.

## Key Concepts
- **Causa aparente x causa real**: "dois motivos para tudo: um bom e o verdadeiro" (citação de Churchill, usada pelo autor).
- **Variáveis que mascaram o efeito**: defeito de produto, toxicidade de lote, mudança de produto, entrada de concorrente com grandes descontos.
- **Roda de muitos raios**: não dá para saber qual raio sustenta a roda sem medir cada um.

## Mental Models
- **Efeito isolado**: pense no anúncio como uma variável entre muitas. Para medir só ele, é preciso uma medida que não dependa das outras (ver ch02).
- **Ruído antes do sinal**: se o caixa caiu, o primeiro passo é procurar outra causa, não culpar o criativo.

## Anti-patterns
- Trocar o criativo porque o faturamento caiu no mesmo dia em que o estoque acabou.
- Dar crédito ao anúncio por uma alta de vendas causada por preço, oferta ou cobertura de distribuição.
- Usar "funciona porque vende" como único critério de aprovação.

## Worked Example (hipotético, adaptado à Meta Ads)
Um e-commerce vê as vendas caírem 30% na semana. Antes de mexer no criativo, a equipe lista o que mudou: o preço subiu 10%, a loja ficou sem estoque em duas linhas e um concorrente lançou cupom. Nenhuma dessas mudanças é o anúncio. A decisão certa é medir lembrança e compra de quem viu o anúncio antes de trocar qualquer peça.

## Key Takeaways
1. Vendas são resultado de muitas variáveis; o anúncio é uma delas.
2. Antes de aprovar ou reprovar uma campanha, liste o que mudou no mesmo período.
3. Julgamento pela venda total engana tanto para o bem quanto para o mal.
4. Precisa-se de uma medida própria do anúncio (ver ch02).
