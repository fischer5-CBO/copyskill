# ch17 — The Emersonian Mousetrap

## Core Idea
Comparar o próprio produto com um concorrente é permitido quando a comparação é verdadeira. O autor separa o que é "competitivo" do que é "desleal" por duas condições: não exagerar uma diferença mínima e citar uma marca de distribuição relevante. Comparação bem feita é um fato, não uma opinião. Mas comparar nem sempre fortalece a campanha.

## Frameworks Introduced
- **Teste de comparação (regras do autor)**:
  1. A comparação é verdadeira. Se é verdade, pode ser dita; se é falsa, fica fora do anúncio.
  2. Não entra no território do diferencial enganoso (ch16).
  3. A marca comparada tem distribuição relevante, não é um produto obscuro vendido em lugares remotos.
- **Quando comparar** — só quando a diferença precisa de comparação para ser entendida. Se o fato é conhecido por todos, fale do próprio produto.

## Key Concepts
- **"Uma ratoeira melhor"**: a frase de Emerson é incompleta; se ninguém sabe que é melhor, ninguém vai à porta.
- **Gritaria sobre "concorrência desleal"**: o autor diz que o termo é usado de forma solta, misturando competitivo, derrogatório e desleal.
- **Modo da fala é questão de estilo**: como dizer a verdade é escolha de copy; o que se diz precisa ser verdadeiro.
- **Exemplos do autor**: "WHY BUY OTHER MOUSETRAPS WHICH DON'T WORK ANYWHERE NEAR AS WELL?" e "CATCHES 6 TIMES MORE MICE".
- **Comparar não é garantia de campanha forte**: se a diferença é óbvia, perder tempo com o concorrente é desperdício.

## Mental Models
- **Fato, não opinião**: a comparação é ou não é verdadeira; não é gosto.
- **Espaço é caro**: cada linha usada para citar o concorrente é uma linha a menos para o próprio produto.

## Anti-patterns
- Citar concorrente com dado que não se pode comprovar.
- Comparar com uma marca que quase ninguém compra, para parecer superior.
- Comparar com o concorrente quando o próprio produto não tem nada a dizer.

## Worked Example (hipotético)
Uma marca de fone de ouvido quer dizer que sua bateria dura mais que a dos líderes. Antes de criar o criativo: a comparação tem teste de bateria documentado? A marca comparada é de distribuição ampla? A diferença é perceptível (horas de uso)? Se as três respostas forem sim, a comparação entra. Se não, o criativo fala só da bateria própria, sem nomear ninguém.

## Key Takeaways
1. Comparação com concorrente é permitida se for verdadeira e relevante.
2. Sem prova documentada, a comparação fica fora do anúncio.
3. Comparar não é sempre melhor que falar do próprio produto.
4. Use o teste de três condições antes de produzir.
