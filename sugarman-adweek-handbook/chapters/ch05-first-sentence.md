# The First Sentence (ch05)

**Fonte**: Chapter 5, p. 31-34 (linhas 1486-1592).

## Core Idea
**Axiom 3**: a única função da primeira frase é fazer o leitor ler a segunda. Por isso ela precisa ser **curta, fácil e quase incompleta**. A regra vale para cada frase seguinte: cada uma existe para levar à próxima. Benefício e descrição de produto vêm depois, quando o leitor já está preso.

## Frameworks Introduced
- **Axiom 3**: "O único propósito da primeira frase de um anúncio é fazer você ler a segunda frase."
- **Efeito locomotiva (analogia do trem)**: a partida exige muita energia; depois, cada trecho fica mais fácil. O copy segue o mesmo caminho.
- **Cadeia de frases**: a segunda frase existe para levar à terceira, e assim por diante. Conteúdo vem só quando o leitor já está dentro.

## Key Concepts
- **Frase curta**: as primeiras frases de anúncios do autor quase não são frases ("É fácil.", "Ninguém está imune.", "Isso não devia existir.").
- **Sem palavras longas nem polissílabos**: leitura fácil é gatilho de continuidade.
- **Como na venda pessoal**: se o cliente se distrai nos primeiros minutos, a venda acabou. O mesmo vale para o leitor.
- **Vender no começo raramente funciona**: o autor testou e não conseguiu provar o contrário.

## Mental Models
- **Locomotiva**: o primeiro trecho exige força. Depois o trem anda sozinho.
- **Quebra-cabeça de atenção**: cada frase deixa uma pergunta aberta que só a próxima responde.
- **Mesmo critério para cada frase**: a pergunta de toda frase é "ela leva à próxima?".

## Anti-patterns
- Começar com benefício, ficha técnica ou preço.
- Primeira frase longa, com palavras difíceis e vírgulas demais.
- Esquecer que a primeira frase tem uma única função e tentar informar nela.

## Worked Example (primeira frase, reconstruída)
Produto: uma ferramenta de organização de tarefas.
- Ruim: "Nossa ferramenta inovadora de gestão de tarefas oferece integração com múltiplas plataformas para aumentar sua produtividade."
- Melhor (curto, incompleto, puxa a próxima): "Você já perdeu um prazo por esquecer uma tarefa?" Depois: "Não é falta de organização." (puxa a próxima) "É falta de um lugar só para tudo."

Teste: leia só a primeira frase. Você sente vontade de ler a segunda? Se não, reescreva mais curto.

Adaptação: o gancho nasce da dor da situação, como nos exemplos acima.

## Key Takeaways
1. A primeira frase tem uma única função: levar à segunda.
2. Frase curta, simples e quase incompleta.
3. Benefício e explicação vêm depois que a leitura começou.
4. Cada frase precisa passar o leitor para a próxima.
5. Teste: se a primeira frase não cria vontade de continuar, reescreva.
