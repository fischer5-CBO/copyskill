# Capítulo 23: Rating Your Writing Level (Nível de leitura: Fog Index)
**Fonte**: Advertising Secrets of the Written Word, Joe Sugarman. Páginas aprox. 207-214 (linhas 8183-8302).

## Core Idea
Clareza se mede. O Fog Index (criado por Robert Gunning para jornalistas) estima o nível escolar necessário para entender um texto. Quanto menor o nível, maior o público. Use como checagem de clareza, sem perseguir o número mais baixo à custa do bom senso.

## Frameworks Introduced
- **Fog Index (7 passos)**:
  1. Pegue uma amostra de 100 a 125 palavras do início do anúncio.
  2. Conte as palavras de cada frase. Datas e números valem uma palavra. Orações independentes contam como frases separadas.
  3. Divida o total de palavras pelo número de frases: média de palavras por frase.
  4. Conte as palavras longas (3 ou mais sílabas), excluindo: compostos simples (pawnbroker, yellowtail), nomes próprios e verbos que só ficaram longos com "-ed" ou "-es".
  5. Divida as palavras longas pelo total de palavras: percentual de palavras longas.
  6. Some a média de palavras por frase com o percentual de palavras longas.
  7. Multiplique por 0,4: é o nível escolar.
- **Referências do autor**: livros mais vendidos ficam entre 8ª e 10ª série; Time e The Wall Street Journal em torno da 11ª; a média do público americano lê entre 11ª e 12ª.

## Key Concepts
- Exemplo do autor: anúncio BluBlocker com 102 palavras e 11 frases (média de 9,3 palavras por frase), 3 palavras longas (2,9%). Resultado: 4,9, ou seja, legível para quem tem a 5ª série.
- Regra prática: pegue blocos de 100 palavras de partes diferentes do anúncio para ver se o estilo é consistente.
- Clareza tem relação direta com a resposta em anúncios do autor.

## Mental Models
- Fog Index é como um termômetro: não é a febre, mas mostra se há algo errado.
- Público amplo pede frases curtas; público sofisticado aceita frases longas e palavras difíceis.

## Anti-patterns
- Perseguir Fog Index baixo a qualquer custo: o texto vira infantil.
- Usar palavras difíceis para parecer sofisticado (o autor critica o "pompous snob").
- Medir só o começo do texto e supor que o resto segue igual.

## Worked Example (reconstruído)
Trecho de 100 palavras com 8 frases (média 12,5), e 6% de palavras longas. Soma: 18,5. Multiplicado por 0,4: 7,4, ou seja, a 7ª série. Para o público de classe média, ok. Para um público técnico, pode ser simples demais.

## Key Takeaways
1. Use o Fog Index para checar clareza, em blocos de 100 palavras.
2. Frases curtas e palavras simples ampliam o público.
3. Escolha o nível conforme o público, não só o menor número possível.
4. Teste várias partes do texto, não só o começo.
