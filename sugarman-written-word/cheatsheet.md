# Cheatsheet: regras de decisão (Sugarman)

## Regras "Se X → Y"
- Se o produto é caro → Y: mais copy e mais justificativa lógica (ch14).
- Se o produto é barato e tem visual forte → Y: copy curta funciona (ch14).
- Se o produto é de prevenção e o público não sofreu → Y: reposicione como cura para quem já sente a dor (ch21).
- Se o produto é simples → Y: explique com complexidade (processo, seleção) para dar valor (ch18).
- Se o produto é complexo → Y: explique com simplicidade (ch18, elemento 5).
- Se o produto está fora da linha da marca → Y: justifique a premissa com força real (ch34).
- Se o leitor pode pensar "e se der errado?" → Y: resolva com garantia no texto e no fechamento (ch19).
- Se há uma objeção óbvia → Y: levante e resolva, não ignore (ch27).
- Se a copy desacelera → Y: use semente de curiosidade (ch10).
- Se a conclusão é óbvia → Y: deixe o leitor concluir (ch20).
- Se a primeira frase tem mais de 15 palavras → Y: encurte (ch05).
- Se a palavra é longa e há sinônimo simples → Y: troque (ch23, ch17).
- Se o texto repete ideia → Y: corte a repetição (ch17).
- Se o público é de massa → Y: frase curta e palavra comum (ch23).
- Se o público é sofisticado → Y: frase mais longa e termo técnico aceito (ch23).
- Se a oferta é de baixo risco → Y: diga o risco no cupom e no fechamento (ch24).
- Se a história não é real → Y: use uma história real e verificável (ch08, ch22).
- Se o número não é verificado → Y: confirme a fonte antes de usar (ch19, ch25).
- Se o anúncio tem muitas opções → Y: teste oferta simples (ch19, gatilho 19).
- Se a lista de clientes é fria → Y: teste pequeno (5.000 nomes) antes de mandar 50.000 (ch10).

## Números e limiares do autor (com a fonte)
Tudo abaixo é relato ou opinião do autor, não estudo verificado. Use como hipótese para testar.
- Primeira frase: curta o bastante para levar à segunda (sem número fixo).
- Leitura de 25% do anúncio → alta chance de ler tudo (afirmação do autor, sem fonte).
- Teste com 5.000 nomes antes de 50.000 (conselho do autor, ch10).
- Trial period: mínimo de 1 mês, melhor 2 (opinião/teste do autor, ch18).
- Corte de palavras: 59 para 36 em um exemplo (-40%) (exemplo do autor, ch17).
- Corte de copy em edição: "50 a 80%" pode ser possível (opinião do autor, ch18, elemento 21).
- Fonte serifada: "5 para 1" em teste de compreensão (citação do autor, sem fonte, ch18).
- Headline trocada: +20% de resposta (relato do autor, ch11).
- Garantia de assinatura: resposta dobrou (teste relatado pelo autor, ch19).
- Teste split com uma opção vs. nove: proporção de 3 para 1 (teste relatado pelo autor, ch19).
- Anúncio com 25 erros: média de 20 achados (relato do autor, ch36).

## Fog Index (7 passos)
1. Amostra de 100 a 125 palavras.
2. Conte palavras por frase (datas e números = 1 palavra; orações independentes = frases separadas).
3. Média de palavras por frase.
4. Conte palavras de 3 ou mais sílabas (sem nomes próprios, compostos simples ou verbos que só ficaram longos com -ed/-es).
5. Percentual de palavras longas.
6. Some média + percentual.
7. Multiplique por 0,4 → série escolar.
Referências do autor: best-sellers ~8ª a 10ª série; Time/WSJ ~11ª; público médio americano ~11ª a 12ª (contexto de 1998).

## Tells & smells (sinais de copy ruim)
- Primeira frase longa, com nome do produto e especificação técnica.
- Headline que promete e a copy não entrega.
- Clichês ("a solução que você esperava").
- Número sem fonte ou sem data.
- Escassez ou "esgotado" sem estoque real.
- Garantia que não é explicada.
- Depoimento sem nome, foto ou autorização.
- Objeção que aparece só na última linha, sem resposta.
- Texto que explica o óbvio e não deixa o leitor concluir.
- Layout poluído, caixa alta em excesso, cores gritando.
- Nome de celebridade ou empresa real sem autorização.
- Pedido de compra ausente ou escondido.
