# Ch 17 — What About Your Web Site? (E o seu site?)

## Core Idea
A fórmula de três passos (Promessa, Prova, Preço) pode ser expandida em uma página inteira. Cada etapa vira uma seção com mais texto. O exemplo do livro é um site de violão, criado com a fórmula.

## Frameworks Introduced
- **Expansão da fórmula em página** — cada passo vira uma seção:
  - Promessa: headline principal + subtítulo que explica o benefício.
  - Prova: depoimentos, garantia, estudos, números e autoridade.
  - Preço: chamada repetida para agir, explicação de como e onde comprar, bônus para quem age agora.
  - Quando usar: ao estruturar uma landing page ou página de vendas.
  - Como: escreva cada seção separada, depois leia a página inteira como um fluxo.

## Key Concepts
- Promessa expandida: uma headline com o resultado (tocar qualquer música de que se gosta em um fim de semana) + detalhe do que o leitor vai aprender.
- Prova expandida: lista de segredos ou conteúdos do produto, cada um como um benefício.
- Garantia forte: "no-risk, 100% money-back, 30 days" com linguagem simples.
- Preço com contexto: preço normal riscado + preço de introdução + prazo ("act now").
- Remover o "Clique aqui" genérico e colocar a ação com o benefício.

## Mental Models
- A página é uma sequência de "portas": cada seção mantém o leitor descendo até o botão.

## Anti-patterns
- Prova sem especificidade.
- Garantia escondida ou com letras miúdas.
- Desconto sem data real de término.

## Worked Example (reconstruído)
Estrutura de uma página para um curso:
- Promessa: "[Resultado] em [prazo real]."
- Prova: três conteúdos específicos + depoimento real autorizado + garantia de [dias reais].
- Preço: "De R$ [preço cheio] por R$ [preço da oferta], até [data real]." + botão com a ação.
Use placeholders; números entram só quando verificados.

## Key Takeaways
- Expanda a fórmula em seções, uma por etapa.
- Prova específica e garantia clara.
- Desconto só com prazo real.
- Repita a chamada para agir ao longo da página.
