# Ch 18 — How Long Is Too Long? (Quanto é muito longo?)

## Core Idea
Copy longa vende se for interessante. O tamanho depende do preço: quanto mais dinheiro se pede, mais palavras são necessárias. Tédio é o que mata, não o comprimento.

## Frameworks Introduced
- **Regra do preço x palavras** — quanto mais dinheiro se pede, mais palavras a peça deve ter (regra do autor, em síntese).
  - Quando usar: ao decidir o tamanho de uma página, carta ou e-mail.
  - Como: pense no tamanho da decisão. Pergunta pequena = texto curto. Compra grande = texto longo.
- **Princípio do "mais você conta, mais você vende"** — a copy longa tende a vender melhor, desde que cada linha prenda.

## Key Concepts
- Newsletter grátis ou produto de até cerca de US$ 10: poucas palavras bastam, se o leitor já conhece o produto.
- Equipamento de US$ 15 mil: muitas palavras, porque há muito o que explicar.
- Guia de decisão: se o leitor entende o produto e o preço, o texto pode ser curto. Se não entende, explique com quantas palavras forem necessárias.
- Tédio quebra o transe: quem se entedia sai da página em segundos.

## Mental Models
- O leitor lê o que é interessante para ele, mesmo que seja longo.

## Anti-patterns
- Cortar informação que o leitor precisa para decidir.
- Estender texto com palavras que não dizem nada.

## Worked Example (reconstruído)
Oferta de R$ 97 (curso curto): página com 6 seções curtas, cada uma com um benefício. Oferta de R$ 4.000 (mentoria): página com histórico do método, perguntas frequentes, casos reais autorizados, comparação de alternativas e garantia. Placeholders: [valores reais].

## Key Takeaways
- Tamanho do texto acompanha o tamanho da decisão.
- Copy longa funciona se for interessante.
- Tédio, não extensão, mata a venda.
- Explique o que o leitor precisa para decidir.
