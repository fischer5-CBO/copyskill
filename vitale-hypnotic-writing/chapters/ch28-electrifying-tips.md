# Ch 28 — Electrifying Tips for Creating Breakthrough Writing (Dicas elétricas para escrita de virada)

## Core Idea
Cinco atitudes de pensamento tornam a escrita viva: visualizar a cena, escrever para uma pessoa, sentir a emoção, ir direto ao ponto e não julgar o próprio texto.

## Frameworks Introduced
- **Cinco dicas de escrita viva**:
  1. **See the events (veja o que escreve)** — visualize o personagem, a ação ou o produto. O leitor vê junto. Ou visualize o leitor.
  2. **Write to one person (escreva para uma pessoa)** — um leitor específico cria intimidade. Carta-modelo, para muitos, soa como carta de massa.
  3. **Get excited (fique animado)** — sinta o que escreve. Quem conta histórias com paixão no bar costuma travar ao escrever a mesma história.
  4. **Get to the point (vá ao ponto)** — frases curtas, sem palavra inútil.
  5. **Don't judge (não julgue)** — quem decide é o leitor. Julgar cedo para o rascunho.

## Key Concepts
- Formulário com nome inserido ainda soa "de madeira" (frio). Escrita pessoal vence.
- Quem escreve para muitos perde calor. Escreva para um.
- O Crítico, quando julga cedo, mata o projeto.

## Mental Models
- Escrever é contar uma história para alguém em particular.

## Anti-patterns
- Carta genérica com nome trocado.
- Texto formal e distante em tema emocional.
- Parar um rascunho porque ele "não parece bom".

## Worked Example (reconstruído)
Carta para "o pequeno empresário": "Olá, empreendedor, temos uma solução para você."
Versão para uma pessoa: "Pense no [nome/perfil real] que abre a loja todo dia às 7h. Ele precisa de [resultado real]. Escrevi isto pensando nele."
Placeholders: [perfil real], [resultado real].

## Key Takeaways
- Visualize o que escreve.
- Escreva para uma pessoa, não para uma massa.
- Sinta a emoção e deixe ela aparecer.
- Corte o excesso; não julgue o rascunho.
